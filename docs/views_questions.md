# Reading-view questionnaire

Use this to decide whether the **Chart / Live / Rehearsal / Practice** model is
worth pursuing — or whether some of these collapse into "one surface + a toggle."

Agreed shape so far: **2 surfaces** — `Chart` (one song) + `Player` (setlists) —
with **Live / Rehearsal / Practice as presets** inside Player. The questions below
pressure-test that: each list ends with a "is this its own thing?" gut-check.

Answer inline (a word or two per question is enough). The goal isn't perfect
answers — it's to surface where two "views" are actually the same view.

---

---

## How to read your answers

- If Live's gut-check is "not really distinct" → Live is a **Chart preset**, not a
  surface.
- If Rehearsal's gut-check is "Live with header pinned" → Rehearsal is a **Player
  preset**, not a surface.
- If Practice's gut-check is "tools on top of Chart" → Practice is a **mode**, not a
  surface.
- The more gut-checks land on "preset/mode," the stronger the case for **2 surfaces
  + presets** over four separate views.
