Design decisions — (1) The hub's identity card becomes an editable identity card: title is an inline field, the gold key chip and the BPM/Time/Capo pills edit in place. (2) The edit surface keeps the existing Visual / Form / Raw tabs and the Arrange/Advanced/Tabs sub-modes, but inside a card with the song-map code ribbon at the top. (3) A third Preview card renders the live chart in the chart theme (reusing the hub's reader card). On mobile the preview folds behind a button/FAB so the edit surface gets full width.
Open questions: keep all three edit modes, or make Visual the default and Raw an "advanced" toggle? · Should Save be in the identity card (shown) or a sticky bottom bar like the current editor? · Per-section drag handles (⠿) shown — keep section reordering here or only in the Arrange sub-tab?
